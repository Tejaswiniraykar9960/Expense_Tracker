# 💰 Personal Expense Tracker (Flask + Excel)

A simple **web-based Expense Tracker** built with **Flask** and **Excel (Pandas + OpenPyXL)** for data storage.

## 🚀 Features
- Login system 
- Add, edit, delete expenses
- Dashboard with total expenses
- Data stored in Excel 

## 🛠 Tech Stack
- Python (Flask)
- Pandas + OpenPyXL
- HTML, CSS, Bootstrap

## ▶️ Run Locally
```bash
git clone https://github.com/Tejaswiniraykar9960/expense_tracker.git
cd expense_tracker
pip install -r requirements.txt
python main.py
Open Browser- http://127.0.0.1:5000
